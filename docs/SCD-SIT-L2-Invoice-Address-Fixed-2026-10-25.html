แก้ที่อยู่ Invoice ให้ตรง Preview — ทดสอบซ้ำ SIT L2

25 ตุลาคม 2026 • Production SCD Transport • Deploy commit 166af83

INV-L2-01 ผ่านหลังแก้
Invoice INV-2026-0001 ของ SIT-MEETING-20261025-L2 แสดงแถว Address ตรงกับ Preview: SIT SYNTHETIC ADDRESS - NOT FOR DELIVERY OR PAYMENT อัปเดตเฉพาะเอกสารของ Draft เดิม ไม่สร้าง Invoice ใหม่
ผล HTTP การเปิดเอกสาร สถานะในทะเบียน และภาพหน้าจอเป็นผลจริงบน production ส่วนลูกค้า ที่อยู่ ยอด 1000 บาท ต้นทุน 700 และหลักฐานขนส่งเป็นข้อมูล SIT ทั้งหมด ไม่ส่งอีเมล ไม่เรียกเก็บเงินจริง ไม่ปิดเป็น Billed และยังไม่เปิด Geofencing

1. สิ่งที่แก้

  • แยก renderer ราย House ไป invoice-document.cjs เพิ่มแถว Address จาก Customer แหล่งเดียวกับ Preview ใช้ HTML escaping ป้องกันอักขระพิเศษกลายเป็น markup พร้อมแสดงหลายบรรทัดและตัดบรรทัดยาว
  • Invoice ใหม่จะใช้ template นี้ ส่วน Draft เดิมใช้ POST /api/billing/refresh-document โดยระบุ Invoice ID และ House ให้ตรงกัน ผู้เรียกต้องเป็น Billing/Admin/Executive เอกสารที่ส่งแล้ว/ไม่ใช่ Draft และแบบรวมถูกปฏิเสธ ไม่แก้ทะเบียนบิลหรือข้อมูลงาน
  • เอกสาร HTML ที่สร้างได้รับการลงทะเบียนเป็น InvoiceDocument และเก็บเนื้อหา HTML ในฐานข้อมูลกลางเดิมเพื่ออ่านกลับเมื่อไฟล์ local ไม่อยู่ โดยใช้ ID เดิมเมื่อเรียกซ้ำ ไม่เพิ่ม attachment ซ้ำ บิล L2 ได้ attachment INVOICE-DOC-INV-2026-0001 เพียงรายการเดียว

3. วิธีตรวจซ้ำด้วยบิลเดิม

  1. เข้าระบบด้วย Billing/Admin เปิด งานภาคสนาม → Billing กรอก House SIT-MEETING-20261025-L2 และตรวจว่าเลือก Invoice INV-2026-0001 อย่ากดสร้าง Draft ใหม่
  2. ดู Preview ต้องเห็นลูกค้า SIT ONLY L2 INVOICE - NOT FOR PAYMENT และที่อยู่ SIT ตามข้อความด้านบน ยอดรวม 1000 บาท
  3. เปิด Transport · Terminal · วางบิล ค้น L2 เลือกแท็บวางบิล แล้วกด ดู Invoice ของ INV-2026-0001 หรือเปิด URL เดิมด้านล่าง รีโหลดหน้าเอกสารหากยังเห็นเวอร์ชันเก่า
  4. ตรวจแถว Address ใต้ Customer ต้องตรงกับ Preview พร้อม House L2 และ Total 1000 THB ชื่อ/ที่อยู่ต้องยังเป็น SIT ไม่ใช้ข้อมูลลูกค้าจริง
  5. ตรวจทะเบียนยังมีบิลใบเดิมสถานะ Draft วันที่และยอดเดิม ไม่กดส่งอีเมลหรือปิด Billed ไม่ต้องพิมพ์ป้ายสินค้าใหม่

การอัปเดตเอกสารเดิมรอบนี้เรียกผ่าน API ด้วยสิทธิ์ SIT Billing แล้วอ่านกลับและตรวจ UI จริง ไม่ได้เพิ่มปุ่ม refresh-document ลงหน้าเว็บ หากต้องทดสอบการสร้าง Invoice ใหม่ ให้ใช้ชุด SIT ใหม่ ไม่รีเซ็ตหรือสร้างซ้ำบน L2 นี้
