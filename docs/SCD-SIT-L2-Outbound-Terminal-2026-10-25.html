3. คู่มือทำตามบนหน้าจอสำหรับชุด SIT ใหม่

L2 ปิดแล้ว ใช้ตรวจย้อนหลังเท่านั้น ห้ามย้อนสถานะเพื่อเดินซ้ำ หากทดสอบใหม่ให้ใช้ชุด SIT รอบใหม่ที่ตรวจแยกจากงานจริงและผ่านขั้นก่อนหน้าแล้ว ขั้นปฏิบัติเป็นดังนี้:

  1. ตรวจชุดก่อนเริ่ม: ค้น House ให้ตรง ตรวจลูกค้า SIT ONLY, Master/Flight, receipt ครบ, QA ปัจจุบัน, EI และเอกสาร WH3 พร้อม รวมทั้งคิวรถที่อนุมัติแล้ว อย่าเลือก Master ลูกค้าจริง หาก Master มีหลาย Flight ต้องเลือก Flight ให้ตรงก่อน
  2. ออก Cargo Transfer: ในหน้า Field Ops → Outbound → Admin Docs เลือก House เดียว กรอกวันที่/เวลา WH3 → TG คนขับ ทะเบียน ประเภทรถ ผู้ปล่อย และแนบ Permit ที่มีข้อความ SIT ONLY แล้วออกฟอร์ม ไม่พิมพ์ป้ายสินค้าใหม่
  3. โหลดที่ WH3: เปิดหน้า Transport · Terminal · วางบิล เลือกแท็บ Transport ค้น House และเลือก House ในช่อง “ชุด House และหลักฐานที่จะบันทึก” ให้ตรง กดเริ่มโหลดที่ WH3
  4. ออก WH3: เลือกภาพประตูปิด/รถจำลองในช่องหลักฐาน ใส่ผู้แจ้งและหมายเหตุ SIT ONLY แล้วกด “ออก WH3 ไป Terminal” ตรวจ GoodsLoaded / EnRouteToTerminal รถขาออกต้องตรงกับ AOT เดิม
  5. Terminal รับคิว/รับสินค้า: เข้าด้วยยูส SIT Terminal เลือกแท็บ Terminal, Master จำลอง และ Flight ตรวจข้อความขอบเขตแสดงเฉพาะ House เป้าหมาย แนบหลักฐานคิวแล้วรับคิว จากนั้นแนบหลักฐานรับสินค้าแล้วกดรับสินค้า Terminal
  6. ชั่ง: กดเริ่มในแถวชั่ง กรอกน้ำหนัก Master/Dimension จำลองที่กำหนดในแผนเทส แนบภาพ SIT แล้วกดเสร็จพร้อมหลักฐาน ตรวจเวลาเริ่ม/จบ จากนั้นดาวน์โหลดใบชั่งจาก App เป็น reference ไม่แก้ใบ Cargo เดิมและไม่อ้างเป็นผลเครื่องชั่งจริง
  7. X-Ray: กดเริ่ม X-Ray เลือก Passed แนบหลักฐานจำลอง แล้วจบพร้อมหลักฐาน ตรวจสถานะและเวลา รอบนี้ไม่ได้ทดสอบ Hold/Re-X-Ray
  8. Load: กดเริ่ม Load แนบ Loading Detail SIT แล้วเสร็จพร้อมหลักฐาน ตรวจ ReadyForBilling / terminalClosedAt ขั้นนี้หมายถึงจบ Terminal พร้อมส่งบัญชี ไม่ใช่ Billed
  9. รับเอกสารคืน: Transport ไป Field Ops → Outbound → Admin Docs เลือก House เดียวเดิม เลื่อนลงหัวข้อ “รับ Cargo Transfer ตัวจริงคืน” แนบ Cargo Transfer คืนที่มีลายเซ็นจำลอง แล้วกด “ยืนยันรับเอกสารคืน / Confirm return” จากหน้า Transport กดยืนยันรถว่าง ตรวจ Available ห้ามออก Invoice จากข้อมูลทดสอบ
  10. ตรวจท้าย: รีเฟรชและอ่านสถานะจากเซิร์ฟเวอร์ เปิดหลักฐานทุกใบ เทียบงานอื่นและคลังกับ baseline ตรวจ Geofencing ปิด แล้วปิดสิทธิ์ทดสอบชั่วคราว หากคำขอ timeout ให้ตรวจประวัติ/สถานะก่อน ไม่กดซ้ำทันที

วิธีที่ใช้รอบนี้: ดำเนิน transition และกรณีบล็อกด้วย API บน production ภายใต้ยูส SIT ตามบทบาท พร้อมอ่านกลับและเก็บภาพ UI จริง ไม่อ้างว่าทดสอบทุกปุ่มบนมือถือ กล้อง เครื่องยิงบาร์โค้ด เครื่องชั่ง หรือ X-Ray จริง
